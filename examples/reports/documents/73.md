## Analysis

Status: ok · analysed document version 1.

Microsoft observed unattributed phishing campaigns in July 2026 targeting organizations across multiple industries with deceptively named, legitimate MSP360 RMM installers. Successful installations established persistent remote access and used PowerShell to install ConnectWise ScreenConnect as a second access channel. Attackers then transferred and executed additional utilities supporting information collection and credential-access activity.

Report type: campaign

Huntable: yes. The report provides searchable installer hashes, process relationships, service names, file paths, network domains, installation commands, and post-compromise utility names.

Actors: None recorded

Malware: None recorded

Tools: MSP360 RMM, ConnectWise ScreenConnect, FaronicsDeployAgent.exe, PowerShell, cmd.exe, msiexec.exe, eventcreate.exe, WindVerify.exe, WindowsUpdate.exe, WindowsSecurity\_PIN.exe, WindowsSecurity\_Password.exe, WindowsPassKey.exe, SCHider.exe, PIN.exe, phonepc.exe, DefenderDT.exe, DefenderControl.exe, phonelinkupdate.exe, PhoneLinkPrompt.exe, Passwords.EXE, OpenCamera.exe, open\_phone\_link.exe, MouseHiderGUI.exe, HideUL.exe, HideMouseApp.dll, HideMouse.exe, HideFromControlPanel.exe, HideCursor.exe, BannerHider.exe, WebBrowserBookmarksView.exe, WebBrowserPassView.exe

Step 1: Attackers sent phishing emails linking to actor-controlled landing pages that impersonated familiar business and software workflows.

Step 2: Attackers disguised the MSP360 installer with filenames resembling business documents, invitations, and software installers.
Observables: VIP\_ECARD\_INVITATION\_rmm\_v2.5.0.67\_oid\[redacted\].exe, ZoomSetup\_Installation\_v2.5.0.67\_ oid\[redacted\].exe, PDF Reader & Editor the Adobe Acrobatte\_rmm\_v2.5.0.67\_ oid\[redacted\].exe, RSVP\_INVITATION\_E\_CARD\_rmm\_v2.5.0.67\_ oid\[redacted\].exe, SSA.GOV\_STATEMENT\_rmm\_v2.5.0.67\_ oid\[redacted\].exe

Step 3: Victims downloaded and executed the disguised MSP360 installer from their Downloads directory.
Observables: 108ef7e628d7a20bd6241a5b57149e27a6061f467123eb64061975559f8f73dc, f34330d4c6e0aa978dc3af40360c14b31ad51127

Step 4: The installer requested UAC elevation and continued with elevated privileges when the elevation succeeded.
Observables: System.dll, nsExec.dll, UAC.dll

Step 5: Installation workflows used the Windows command shell for logging, prerequisite checks, file management, and installation tasks.
Observables: cmd.exe, eventcreate.exe, MSP360 RMM Agent installer

Step 6: The installer enumerated installed .NET runtimes to identify prerequisite software.
Observables: dotnet –list-runtimes

Step 7: MSP360 and subsequently ScreenConnect were installed as Windows services to maintain persistent access.
Observables: RMM.Agent.exe, RMM.Agent.Launcher.exe, C:\\Program Files\\RMM Agent\\, ScreenConnect.ClientService.exe

Step 8: MSP360 created registry Run entries to launch its tray components automatically at user logon.

Step 9: The installer added a Windows Firewall inbound allow rule for the MSP360 agent.
Observables: C:\\Program Files\\RMM Agent\\RMM.Agent.exe, 48678

Step 10: Attackers abused MSP360 and ScreenConnect as redundant remote administration channels to maintain access.
Observables: RMM.Agent.exe, ScreenConnect.ClientService.exe, ScreenConnect.WindowsClient.exe, ScreenConnect.Client.exe, adswre\[.\]cfd, trews\[.\]cfd, swedcorry\[.\]stefneyv\[.\]com, ojsuyw\[.\]niyari\[.\]org, bunstar\[.\]harej\[.\]si, adsaw\[.\]cfd, sdfghj\[.\]rd-team\[.\]ru

Step 11: The MSP360 agent launched PowerShell to download and install ScreenConnect.
Observables: RMM.Agent.exe, powershell.exe, Invoke-WebRequest

Step 12: MSP360 downloaded ScreenConnect, and attackers subsequently transferred additional tooling through ScreenConnect.
Observables: Invoke-WebRequest, ClientSetup.msi, C:\\Users\\%user%\\OneDrive\\Documents\\ScreenConnect\\Temp\\, C:\\Users\\%user%\\Documents\\ScreenConnect\\Temp\\

Step 13: PowerShell and ScreenConnect communicated with actor-controlled infrastructure using HTTP or HTTPS.
Observables: ScreenConnect.ClientService.exe, ScreenConnect.WindowsClient.exe, adswre\[.\]cfd, trews\[.\]cfd, swedcorry\[.\]stefneyv\[.\]com, ojsuyw\[.\]niyari\[.\]org, bunstar\[.\]harej\[.\]si, adsaw\[.\]cfd, sdfghj\[.\]rd-team\[.\]ru

Step 14: Payload retrieval and remote access communications used encrypted network channels.

Step 15: Attackers used cloud-hosted web services in their delivery and command-and-control infrastructure.
Observables: Amazon S3, Cloudflare R2, Dropbox, GitLab, Supabase

Step 16: The downloaded ScreenConnect MSI package was installed silently using msiexec.
Observables: ClientSetup.msi, msiexec.exe /qn

Step 17: The RMM installations modified registry locations for services, persistence, credential providers, protocol handlers, and uninstall entries.

Step 18: Attackers named follow-on utilities to resemble legitimate Windows, Defender, security, and Phone Link components.
Observables: WindowsUpdate.exe, WindowsSecurity\_PIN.exe, WindowsSecurity\_Password.exe, WindowsPassKey.exe, DefenderDT.exe, DefenderControl.exe, phonelinkupdate.exe, PhoneLinkPrompt.exe

Step 19: Attackers executed transferred utilities through ScreenConnect's built-in software deployment functionality.
Observables: RunFile, ScreenConnect.WindowsClient.exe, C:\\Users\\%user%\\OneDrive\\Documents\\ScreenConnect\\Temp\\, C:\\Users\\%user%\\Documents\\ScreenConnect\\Temp\\, WebBrowserBookmarksView.exe, WebBrowserPassView.exe, Passwords.EXE, OpenCamera.exe

Step 20: Additional tooling delivered through ScreenConnect collected information from victim devices.
